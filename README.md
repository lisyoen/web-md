# web-md

임의의 웹페이지 본문을 Markdown 으로 추출해 다운로드하는 Chrome 확장입니다.

툴바 아이콘을 클릭하면 현재 페이지의 메인 컨텐츠를 추출·정제해 `{페이지제목}.md` 파일로 저장합니다.
LLM 프롬프트/컨텍스트로 붙여넣기 좋도록 텍스트·표·링크를 충실히 옮기고 이미지·첨부는 제외합니다.

## 특징

- 도메인 제약 없음 (`<all_urls>`)
- 범용 본문 추출 휴리스틱 (article / main / [role=main] 등 시맨틱 후보 + 텍스트 밀도 스코어링)
- 네비게이션·헤더·푸터·사이드바·광고 등 노이즈 제거
- GFM 표, fenced code block, 작업목록 체크박스 지원
- 로컬 변환만 수행하며 페이지 내용을 외부로 전송하지 않음

## 설치

1. 이 저장소를 clone 합니다.
2. Chrome 에서 `chrome://extensions` → 개발자 모드 ON → "압축해제된 확장 프로그램을 로드합니다" → `extension` 폴더 선택
